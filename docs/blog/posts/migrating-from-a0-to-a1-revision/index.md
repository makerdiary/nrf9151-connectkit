# Migrating from A0 to A1 Revision

We are pleased to announce that the nRF9151 SiP module on the nRF9151 Connect Kit has been updated from revision A0 to A1, adding support for Non-Terrestrial Networks (NTN).

This update is now applied to all new nRF9151 Connect Kits.

## What This Means for You

The A1 revision represents the latest hardware version of the nRF9151 SiP. With NTN support, the module enables satellite-based NB-IoT connectivity via 3GPP-compliant NTN bands B23/B252, B255 and B256, allowing IoT devices to communicate in remote areas without terrestrial cellular coverage.

By using the updated Connect Kit, you are developing and testing on the same silicon revision recommended for mass production, including NTN-enabled applications.

Please note that to support the A1 module, nRF Connect SDK has been upgraded to `v3.3.99-95ed8f7e7406`, and the modem firmware has been upgraded to `v2.0.4`. All samples, applications, and documentation will be released based on `v2.0.0`. The new release `v2.0.0` is also fully compatible with the A0 revision module.

## Availability

All new nRF9151 Connect Kits shipped from Makerdiary now include the A1 revision of the nRF9151 SiP.

Thank you for choosing our nRF9151 Connect Kit for your low-power Cellular IoT projects.
